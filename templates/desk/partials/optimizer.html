Equal Sharpe prior

Every name is assumed to earn the same Sharpe ratio: expected excess return = k × predicted volatility from the covariance matrix. Historical means are ignored. For Maximum Sharpe, k cancels and the solve is the Maximum Diversification Portfolio w ∝ Σ⁻¹σ.

Annual factor premiums

Expected stock return = risk-free rate + beta × premium; regression alpha is excluded. Each premium is a prior: every run blends it toward the trailing factor mean in proportion to how precisely that mean is measured, so backtest months re-estimate from data available at the time.
